# Northwind SQL Data Analysis Project

This project is based on a structured training assignment using the Northwind dataset.

The goal of the project was to practice SQL data analysis techniques, including querying relational data, performing aggregations, and extracting business insights.

All queries and analyses were implemented as part of a learning process.

---

## 📊 Project Overview

The objective of this project is to analyze sales, customers, products, and categories using SQL queries.  
Each query answers a specific business question, such as:

- Which categories contain the most products?
- What are the monthly sales trends?
- Which products generate the highest or lowest revenue?
- How active are customers in different countries?
- What are customer activity patterns in the USA?

---

## 🗂️ Dataset

The project uses the Northwind sample database, including the following tables:

- Customers  
- Orders  
- Order Details  
- Products  
- Categories  
- Suppliers  

The dataset and database schema were provided as part of the training assignment.

---

## 🧠 Key SQL Concepts Used

- INNER JOINs across multiple tables  
- GROUP BY and aggregation functions (COUNT, SUM)  
- Filtering with WHERE and HAVING  
- Date extraction (YEAR, MONTH)  
- String aggregation (STRING_AGG)  
- Revenue calculations with discount logic  
- Sorting and limiting results  

---

## 📈 Example Analyses

- Product distribution per category  
- Revenue by product  
- Monthly sales performance (1997)  
- Lowest-performing products (bottom revenue)  
- Customer distribution by country  
- Low-activity customers in the USA  
- Supplier-product relationships
