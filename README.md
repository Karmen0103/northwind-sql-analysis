# 🗄️ **Northwind SQL Data Analysis Project**

## 📌 **Overview**
This project explores business data from the Northwind database using SQL. The focus is on analyzing sales performance, customers, products, and categories to extract meaningful business insights.

## 📊 **Key Analysis**
* Sales performance across products and categories  
* Revenue analysis and product comparison  
* Monthly sales trends  
* Customer activity by country  
* Identification of low-performing products  

## 🗂️ **Dataset**
* Northwind relational database (Customers, Orders, Order Details, Products, Categories, Suppliers)

## 🧠 **Skills Demonstrated**
* SQL joins across relational tables  
* Aggregations (SUM, COUNT)  
* GROUP BY, HAVING, WHERE  
* Date-based analysis  
* Business-oriented querying  

## 🎯 **Outcome**
This project demonstrates the ability to work with relational databases and translate business questions into SQL-based analysis.

## 📌 **Notes**
This project was completed as part of a structured learning exercise.  

Some parts of the work were developed in a collaborative learning environment, but the queries and analyses presented here reflect my own understanding of SQL and data analysis concepts.
